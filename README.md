# memes-shelf
You can use this app as a shelf to put your memes in ( images, audios, stickers) and share it anytime , anywhere

##here are the extensions used:
-images ['jpg', 'png', 'jpeg']
-audios ['mp3', 'wav', 'aac', 'opus']
-stickers ['webp', 'gif']
-videos ['mp4','avi','mkv','mov','wmv','flv','webm']

##features used:
  -share files
  -receive files
  -rename files
  -search for file
  -select multiple files
